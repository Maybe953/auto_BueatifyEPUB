# 自定义精排内嵌字体使用说明

本文件夹是 EPUB Auto-Beautifier 专属的字体存放目录（`fonts/`）。

## 1. 默认已自动下载的优秀开源字体
我们已使用高速 CDN 镜像为您自动下载了以下 3 款备受推崇且完全免费商用的电子书阅读字体：
- **霞鹜文楷 Lite** (`LXGWWenKaiLite-Regular.ttf`) —— 轻量优化的文楷，适合手机端及电子书独立阅读，也是本系统的推荐首选。
- **霞鹜文楷 GB** (`LXGWWenKaiGB-Regular.ttf`) —— 针对中国大陆国标字符规范的版本。
- **霞鹜文楷 TC** (`LXGWWenKaiTC-Regular.ttf`) —— 针对繁体中文排版规范的版本。

## 2. 如何添加自定义字体（如“仓耳今楷”、“方正宋体”等）
由于“仓耳今楷”等是受版权保护的商业字体，系统无法直接在互联网源进行公共托管下载。如果您自备了这些字体，可以非常方便地加入本系统：

1. 准备好您的字体文件（支持 `.ttf`、`.otf` 或 `.woff2` 格式）。
2. 将该字体文件直接复制或拖入到当前 `fonts/` 目录下。
   - 例如：如果您自备了仓耳今楷，只需把字体文件命名为 `TsangerJinKai01-W03.ttf` 并放进来即可。
3. 重新刷新网页控制台，排版字体族的下拉选择菜单中便会自动识别、装载并显示您添加的自定义字体！
4. 选中它即可进行高保真左右双栏对比预览，且在最终精排导出时，系统会自动将该字体安全内嵌封装进您的 EPUB 电子书包中，使您在阅读器中尽享完美的高级精排排版！
